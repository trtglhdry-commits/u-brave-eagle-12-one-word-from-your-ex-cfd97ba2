## The word

> **unavailable**

The one word an ex would use to describe the entrant. It is the classic
verdict: painfully honest, instantly relatable, and it lands without
explanation. Not an insult — a diagnosis the entrant plainly knows is
true. No near-synonym carries the same edge: "busy" is an excuse,
"distant" is cold, "gone" is already over.

## How it works

`main.ts` (Node 22) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), enforcing the competition gate itself:
exactly one word, 1–24 characters, no whitespace.

```sh
node main.ts
cat /output/entry.txt  # unavailable
```
